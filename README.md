# 🪐 URANUS — بوت واتساب (Lynox)

🌐 **الموقع:** https://lynox.duckdns.org/

بوت واتساب مبني على **Baileys** و**Node.js**، فيه أكتر من 200 أمر (ألعاب، تحميل، ستيكرز، إدارة جروبات، ذكاء اصطناعي وغيرها)، ونظام تنصيب بوتات فرعية عن طريق تيليجرام أو موقع ويب.

---

## ✅ المتطلبات

- Node.js 18 أو أحدث
- git
- ffmpeg (لأوامر الصوت والفيديو والستيكرز)
- حساب واتساب مخصص للبوت

---

## ⚙️ الإعدادات (`settings.js`)

افتح `settings.js` واستبدل كل قيمة مكتوب مكانها وصف بالقيمة الحقيقية:

| المتغير | القيمة اللي تتحط مكانه |
|---|---|
| `global.owner` | `ليد المالك 1@lid` ... — الـ lid بتاعك (تجيبه من أمر `lid` في البوت) |
| `global.botNumberCode` | `رقم الربط` — رقم البوت بكود الدولة من غير `+` |
| `global.telegramInstallerToken` | `توكن بوت التيليجرام` — من BotFather |
| `global.telegramOwnerID` | `ايدي المالك في التيليجرام` — رقم فقط، من بوت زي @userinfobot |
| `global.ch` | `ايدي القناة 1` / `ايدي القناة 2` — ايدي قنواتك (اختياري) |

### مفاتيح وبيانات تانية في الملفات

| الملف | المطلوب |
|---|---|
| `plugins/فحص.js` و`plugins/ai-helper.js` | `مفتاح API` — مفتاح Groq بتاعك |
| `plugins/جبتي.js` | `الكوكيز` — كوكيز الموقع (اختياري) |
| `System/ytdlp.js` | قيم كوكيز انستجرام (اختياري، لتحميل انستجرام) |
| الملفات اللي فيها `رقم المطور 1` ... `رقم المالك` | استبدلها بأرقام المطورين عندك |
| الملفات اللي فيها `ايدي الجروب 1` وشبهه | استبدلها بمعرفات جروباتك |

> ⚠️ **تنبيه:** ما ترفعش قيمك الحقيقية على جيتهاب. لو الريبو public أي حد هيشوفها.

## ▶️ التشغيل

```bash
npm start          # تشغيل عادي (هيسألك طريقة الربط)
npm run code       # الربط بكود (pairing code)
npm run qr         # الربط بـ QR
```

بعد الربط الجلسة بتتحفظ، والتشغيل بعد كده بيكمل لوحده.

### ربط بكود
1. حط رقمك في `global.botNumberCode`.
2. شغّل `npm run code`.
3. افتح واتساب ثم الأجهزة المرتبطة ثم ربط برقم الهاتف، وادخل الكود اللي ظهر.

## 🔄 لانشر تلقائي (للاستضافة)

لو الاستضافة بتاعتك بتشغّل ملف `index.js` بس، استخدم ملف اللانشر الصغير: بيحمّل البوت من جيتهاب، يثبّت الحزم، ويشغّله، ويعيد تشغيله لو وقف.

| متغير بيئة | الوظيفة |
|---|---|
| `GITHUB_TOKEN` | لو الريبو private |
| `AUTO_UPDATE=0` | إيقاف التحديث التلقائي |
| `BOT_BRANCH` | اسم فرع معين |
| `SERVER_PORT` | منفذ موقع التنصيب (الافتراضي 24691) |

## 🤖 تنصيب بوتات فرعية

- **من تيليجرام:** فعّل `telegramInstallerEnabled` وحط التوكن والآيدي، وبعدها بوت التيليجرام بيستقبل الأرقام وينصّب البوتات.
- **من الموقع:** السيرفر الداخلي (`server.js`) بيفتح صفحة تنصيب على المنفذ الموضح فوق.
- **من واتساب:** أمر `.تنصيب 20XXXXXXXXXX`.

## 🗂️ هيكل المشروع

```
├── index.js          # نقطة التشغيل والاتصال بواتساب
├── handler.js        # معالج الرسائل والأوامر
├── settings.js       # الإعدادات
├── server.js         # موقع تنصيب البوتات الفرعية
├── plugins/          # الأوامر (كل ملف = أمر)
├── System/           # ملفات النظام والواجهة
├── lib/              # مكتبات مساعدة
├── telegram/         # بوت تنصيب تيليجرام
├── database/         # قاعدة البيانات
├── data/             # بيانات الألعاب والإعدادات
└── src/              # ملفات إضافية (أسئلة الألعاب وغيرها)
```

### إضافة أمر جديد
اعمل ملف جديد في `plugins/` وصدّر `handler` بنفس شكل باقي الملفات، والبوت بيحمّله تلقائياً من غير ريستارت.
